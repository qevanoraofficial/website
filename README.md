# QEVANORA OFFICIAL — Next.js

Versi dengan motion system bergaya ITzpire:
- animasi masuk pertama: fade + slide-up bertahap pada hero
- scroll reveal: judul, teks, card, FAQ, footer muncul dari bawah saat masuk viewport
- animasi hanya sekali per elemen
- tanpa dependency animasi tambahan
- responsive mobile / desktop

Run:
```bash
npm install
npm run dev
```
